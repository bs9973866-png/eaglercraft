Файл на устройстве
Важно: стандартные Java-версии вроде 1.8.9, 1.16.5, 1.20.4 и 1.21.11 не запускаются автоматически одним только WebView. Для них нужен отдельный совместимый клиент/рантайм; в этом приложении не подменяем их несуществующими сборками.

Офлайн-клиент

Загрузи локальный автономный клиент, чтобы открывать его без сайта-источника. Многопользовательская игра всё равно требует сети.

⇧

Импортировать автономный HTML

Выбери .html или .htm из памяти телефона. Файл копируется в приватное хранилище NovaBlock и запускается в полноэкранном WebView. Для ZIP-сборки сначала распакуй архив и выбери итоговый HTML.

▣

Как получить автономный клиент

Открой официальный каталог загрузок, скачай нужный офлайн-пакет, распакуй ZIP при необходимости и выбери самодостаточный HTML. Не импортируй исполняемые файлы APK/EXE или неизвестные скрипты.

Память: автономные HTML-клиенты могут занимать десятки мегабайт. Приложение хранит выбранный файл во внутреннем хранилище; удаление данных приложения удалит и импортированный клиент.
