# NovaBlock

Browser Minecraft project shell. The Android build is designed to wrap the web client in a fullscreen WebView with touch controls.

## Structure
- `web/` — NovaBlock web UI and runtime entry point
- `android/` — Android wrapper project

## Important
Keep the Minecraft/Eaglercraft runtime separate and only distribute code/assets you are legally permitted to distribute. This repository contains the NovaBlock shell and build scaffolding.
